# Privacy

Codex Video Factory 0.1.0 processes explicitly authorized local files. It does not require an API key,
send media to a remote generation service, install software, or collect analytics. Plans, ledgers,
temporary segments, review videos, final artifacts, and receipts remain under paths chosen by the user.

The plugin rejects network URLs, symbolic-link escapes, special files, undeclared credentials, and asset
hash mismatches. Users remain responsible for the rights and consent needed to process people, music,
footage, subtitles, logos, and other supplied material.
